# Results entry and branded result slips

Raymond Ryam’s corrected entry date is **January 2026**.

## Admin workflow

1. Sign in with the configured KeMU administrator Manus account.
2. Open **Results & Slips** in the administrator sidebar.
3. Select a student.
4. Select the course.
5. Enter the semester, for example `Semester 3, 2026`.
6. Enter official marks, grade, and optional grade point when they are available.
7. Leave marks and grade blank if the result is not yet official. The entry is saved as **Pending**.
8. Click **Save result**.
9. Click **Print slip** for the relevant student.
10. In the browser print dialog, select **Save as PDF**.

## Student workflow

A student opens **Results** after signing in. Published values appear in the table. Pending entries are clearly labelled and are not presented as official results. The student can use **Download result slip** and choose **Save as PDF**.

## Academic integrity

The portal does not generate or guess marks, grades, grade points, GPA, fee balances, or official results. Administrators must enter values supplied by the Academic Registry. A blank result is stored as Pending.

## Fee statements

The supplied source does not invent fee charges or payments. A fee-statement PDF should be added only after the approved programme fee schedule, payment ledger, waivers, and balance rules are supplied. The same KeMU logo/contact header can then be used for that document.
